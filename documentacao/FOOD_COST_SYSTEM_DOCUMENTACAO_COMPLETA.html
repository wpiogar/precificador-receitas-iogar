Visão Geral

Contexto e características do Food Cost System

🎯 Contexto do Projeto

O Food Cost System é uma solução completa de gestão de custos desenvolvida pela IOGAR Consultoria para restaurantes e empresas de food service. O sistema permite controle detalhado de ingredientes, receitas, fornecedores e análises de rentabilidade.

💰
Gestão de Custos
Controle completo de preços por fornecedor, cálculo automático de custos e histórico de variações
🤖
Inteligência Artificial
Classificação automática de ingredientes com NLP e sistema de aprendizado contínuo 100% gratuito
🔐
Segurança Total
JWT com refresh tokens, 5 níveis de acesso e permissões configuráveis por recurso
📊
Relatórios Profissionais
PDFs com marca IOGAR, fichas técnicas, exportação Excel/CSV e cardápios personalizáveis
🏢
Multi-Tenancy
Suporte a múltiplos restaurantes com isolamento de dados e compartilhamento opcional
📈
Receitas Hierárquicas
Receitas processadas como ingredientes, cálculo em cascata e mise en place automatizado

Objetivo do Projeto

Problema, solução e benefícios esperados

⚠️ Problema de Negócio

Restaurantes enfrentam desafios críticos na gestão de custos:

  • Descontrole de variação de preços sem rastreamento
  • Cálculos manuais em planilhas Excel sem automação
  • Falta de visão sobre custos reais de cada prato
  • Dificuldade em comparar e negociar com fornecedores
  • Desperdício por falta de controle de yield e perdas
  • Precificação sem embasamento técnico adequado
💡 Solução Proposta

O Food Cost System resolve através de: automação completa de cálculos, classificação inteligente com IA, importação em massa via Excel, base única centralizada e relatórios profissionais prontos.

🍽️
Para o Restaurante
Redução de custos em 15-20%, aumento de margem e decisões baseadas em dados reais
👨‍💼
Para o Consultor
Ferramenta profissional, ganho de 70% em produtividade e base compartilhada de conhecimento

Arquitetura do Sistema

Estrutura em três camadas e padrões de projeto

┌─────────────────────────────────────────┐ │ CAMADA DE APRESENTAÇÃO │ │ React 18 + TypeScript + Tailwind │ │ - SPA com routing │ │ - State management local │ │ - Axios para HTTP │ └─────────────────────────────────────────┘ │ HTTPS / REST API ▼ ┌─────────────────────────────────────────┐ │ CAMADA DE APLICAÇÃO │ │ FastAPI + Python 3.11 │ │ - Endpoints REST │ │ - Autenticação JWT │ │ - Validação Pydantic │ │ - Sistema de IA (spaCy) │ └─────────────────────────────────────────┘ │ SQLAlchemy ORM ▼ ┌─────────────────────────────────────────┐ │ CAMADA DE PERSISTÊNCIA │ │ PostgreSQL 15 + Redis 7 │ │ - Dados principais │ │ - Cache e sessões │ └─────────────────────────────────────────┘

🏗️ Design Patterns Utilizados

Repository Pattern (crud/) - Abstração de acesso a dados, facilita testes e separa lógica de negócio do banco

Service Layer Pattern (services/) - Lógica de negócio centralizada, reutilização entre endpoints e orquestração de operações complexas

Dependency Injection - FastAPI dependency injection system, injeção de sessões de banco e usuário atual

DTO Pattern (schemas/) - Validação automática com Pydantic, serialização/deserialização e documentação automática da API

Instalação e Configuração

Guia completo para rodar o sistema localmente

📋 Pré-requisitos

Antes de começar, certifique-se de ter: Docker Desktop, Git e VS Code (recomendado) instalados no seu sistema.

1️⃣ Passo 1: Clonar Repositório

# Clone o projeto git clone https://github.com/iogar/food-cost-system.git cd food-cost-system

2️⃣ Passo 2: Configurar Variáveis

# Copiar template cp .env.example .env # Editar .env (IMPORTANTE: alterar senhas!) DATABASE_URL=postgresql://postgres:senha@db:5432/foodcost_db SECRET_KEY=gerar_chave_segura_aqui ALLOWED_ORIGINS=http://localhost,http://localhost:3000

3️⃣ Passo 3: Iniciar Sistema

# Iniciar containers docker-compose up -d # Verificar status docker-compose ps # Ver logs docker-compose logs -f

🌐 Acessar o Sistema

Serviço URL Descrição
Frontend http://localhost Interface principal
Backend API http://localhost:8000 API REST
Swagger http://localhost:8000/docs Documentação API
PostgreSQL localhost:5432 Banco de dados

Visão Geral

Contexto e características do Food Cost System

🎯 Contexto do Projeto

O Food Cost System é uma solução completa de gestão de custos desenvolvida pela IOGAR Consultoria para restaurantes e empresas de food service. O sistema permite controle detalhado de ingredientes, receitas, fornecedores e análises de rentabilidade.

💰
Gestão de Custos
Controle completo de preços por fornecedor, cálculo automático de custos e histórico de variações
🤖
Inteligência Artificial
Classificação automática de ingredientes com NLP e sistema de aprendizado contínuo 100% gratuito
🔐
Segurança Total
JWT com refresh tokens, 5 níveis de acesso e permissões configuráveis por recurso
📊
Relatórios Profissionais
PDFs com marca IOGAR, fichas técnicas, exportação Excel/CSV e cardápios personalizáveis
🏢
Multi-Tenancy
Suporte a múltiplos restaurantes com isolamento de dados e compartilhamento opcional
📈
Receitas Hierárquicas
Receitas processadas como ingredientes, cálculo em cascata e mise en place automatizado

Objetivo do Projeto

Problema, solução e benefícios esperados

⚠️ Problema de Negócio

Restaurantes enfrentam desafios críticos na gestão de custos:

  • Descontrole de variação de preços sem rastreamento
  • Cálculos manuais em planilhas Excel sem automação
  • Falta de visão sobre custos reais de cada prato
  • Dificuldade em comparar e negociar com fornecedores
  • Desperdício por falta de controle de yield e perdas
  • Precificação sem embasamento técnico adequado
💡 Solução Proposta

O Food Cost System resolve através de: automação completa de cálculos, classificação inteligente com IA, importação em massa via Excel, base única centralizada e relatórios profissionais prontos.

🍽️
Para o Restaurante
Redução de custos em 15-20%, aumento de margem e decisões baseadas em dados reais
👨‍💼
Para o Consultor
Ferramenta profissional, ganho de 70% em produtividade e base compartilhada de conhecimento

Tipo de Receita Faixa de Código Características
NORMAL 3000-3999 Pratos finais para venda (ex: Pizza, Hambúrguer)

# Estrutura de uma Receita DADOS BÁSICOS: ├── Código automático ├── Nome da receita ├── Tipo (NORMAL ou PROCESSADA) ├── Categoria (entrada, prato principal, sobremesa) ├── Rendimento em porções └── Foto (upload Cloudinary) INGREDIENTES: ├── Lista de insumos necessários ├── Quantidade de cada ingrediente ├── Unidade de medida ├── Custo unitário (snapshot) └── Custo total calculado automaticamente CÁLCULOS: ├── CMV Total = Σ (quantidade × custo_unitário) ├── Custo por Porção = CMV / rendimento_porcoes ├── Margem de Lucro = (Preço Venda - CMV) / Preço Venda × 100 └── Sugestão de Preço = CMV / (1 - markup_desejado) HIERARQUIA: ├── Receitas processadas podem ser ingredientes ├── Cálculo em cascata de custos ├── Atualização automática ao mudar preços └── Detalhamento completo em PDF
⚠️ Receitas Hierárquicas

Uma receita PROCESSADA (4000-4999) pode ser usada como ingrediente em outra receita NORMAL (3000-3999). Por exemplo: "Molho Especial" (4001) pode ser ingrediente de "Pizza Margherita" (3050).

# backend/app/core/security.py from datetime import datetime, timedelta from jose import jwt, JWTError from passlib.context import CryptContext # Configurações SECRET_KEY = os.getenv("SECRET_KEY") ALGORITHM = "HS256" ACCESS_TOKEN_EXPIRE_MINUTES = 30 REFRESH_TOKEN_EXPIRE_DAYS = 7 # Contexto para hash de senhas (bcrypt) pwd_context = CryptContext(schemes=["bcrypt"], deprecated="auto") # Função: Criar Access Token def create_access_token(data: dict) -> str: to_encode = data.copy() expire = datetime.utcnow() + timedelta(minutes=ACCESS_TOKEN_EXPIRE_MINUTES) to_encode.update({ "exp": expire, "iat": datetime.utcnow(), "type": "access" }) return jwt.encode(to_encode, SECRET_KEY, algorithm=ALGORITHM) # Função: Criar Refresh Token def create_refresh_token(data: dict) -> str: to_encode = data.copy() expire = datetime.utcnow() + timedelta(days=REFRESH_TOKEN_EXPIRE_DAYS) to_encode.update({ "exp": expire, "iat": datetime.utcnow(), "type": "refresh" }) return jwt.encode(to_encode, SECRET_KEY, algorithm=ALGORITHM) # Função: Decodificar e Validar Token def decode_token(token: str) -> dict: try: payload = jwt.decode(token, SECRET_KEY, algorithms=[ALGORITHM]) return payload except JWTError: return None # Função: Verificar Senha def verify_password(plain: str, hashed: str) -> bool: return pwd_context.verify(plain, hashed) # Função: Hash de Senha def get_password_hash(password: str) -> str: return pwd_context.hash(password)

# backend/app/ai/classificador_ia.py import spacy from fuzzywuzzy import fuzz, process import unidecode class ClassificadorIA: def __init__(self, db_session): self.db_session = db_session # Carregar modelo português self.nlp = spacy.load("pt_core_news_sm") def normalizar_texto(self, texto: str) -> str: """Remove acentos, lowercase, limpa texto""" texto = unidecode.unidecode(texto) texto = texto.lower().strip() return texto def extrair_tokens(self, texto: str) -> list: """Tokeniza e remove stopwords""" doc = self.nlp(texto) tokens = [ token.lemma_ for token in doc if not token.is_stop and not token.is_punct ] return tokens def calcular_similaridade(self, texto1: str, texto2: str) -> float: """Calcula similaridade entre dois textos""" ratio = fuzz.ratio(texto1, texto2) partial = fuzz.partial_ratio(texto1, texto2) token_sort = fuzz.token_sort_ratio(texto1, texto2) token_set = fuzz.token_set_ratio(texto1, texto2) # Retornar melhor score return max(ratio, partial, token_sort, token_set) / 100.0 def classificar_produto(self, nome_produto: str) -> dict: """Método principal de classificação""" candidatos = [] # 1. Buscar em aliases (prioridade máxima) alias_result = self._buscar_em_aliases(nome_produto) if alias_result and alias_result['score'] >= 0.95: return alias_result # 2. Buscar em mapeamento inteligente mapeamento_results = self._buscar_mapeamento(nome_produto) candidatos.extend(mapeamento_results) # 3. Análise NLP complementar nlp_results = self._analisar_nlp(nome_produto) candidatos.extend(nlp_results) # 4. Ordenar por score e retornar melhor candidatos.sort(key=lambda x: x['score'], reverse=True) return { 'taxonomia_sugerida': candidatos[0] if candidatos else None, 'score_confianca': candidatos[0]['score'] if candidatos else 0, 'alternativas': candidatos[1:4] if len(candidatos) > 1 else [] } def registrar_feedback(self, produto: str, taxonomia_correta_id: int): """Salva feedback para aprendizado contínuo""" # Criar novo alias alias = TaxonomiaAlias( alias=self.normalizar_texto(produto), taxonomia_id=taxonomia_correta_id, confianca=0.95 ) self.db_session.add(alias) self.db_session.commit() # Log para análise logger.info(f"Feedback registrado: {produto} → {taxonomia_correta_id}")
